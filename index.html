    Excel Pro Shortcuts

    Cell Size, Row & Column Adjustment Shortcuts

    Shortcut Action Explanation
    Alt + H + O + I AutoFit Column Width Automatically adjusts column width to fit the longest text/data.
    Alt + H + O + A AutoFit Row Height Automatically adjusts row height according to cell content.
    Alt + H + O + W Set Column Width Opens option to manually enter column width.
    Alt + H + O + H Set Row Height Opens option to manually enter row height.
    Double-click Column Border AutoFit Column Quickly adjusts column size to fit content.
    Double-click Row Border AutoFit Row Quickly adjusts row height.
    Ctrl + Space → Alt + H + O + W Change Entire Column Width Selects full column and changes its width.
    Shift + Space → Alt + H + O + H Change Entire Row Height Selects full row and changes its height.
    Ctrl + A → Alt + H + O + I AutoFit Entire Sheet Columns Fits all columns in the worksheet automatically.
    Ctrl + A → Alt + H + O + A AutoFit Entire Sheet Rows Fits all rows in the worksheet automatically.

    Alignment & Spacing Shortcuts

    Shortcut Action Explanation
    Alt + H + A + C Center Align Places text in the center of cells.
    Alt + H + A + L Align Left Moves content to the left side.
    Alt + H + A + R Align Right Moves content to the right side.
    Alt + H + A + T Align Top Places content at the top of the cell.
    Alt + H + A + M Align Middle Centers content vertically.
    Alt + H + A + B Align Bottom Places content at the bottom of the cell.
    Alt + H + W Wrap Text Makes long text appear on multiple lines inside a cell.
    Alt + H + M + M Merge & Center Combines selected cells and centers text.
    Alt + H + M + C Merge Cells Joins selected cells without centering.
    Alt + H + M + U Unmerge Cells Separates merged cells.

    Font Size & Cell Formatting Shortcuts

    Shortcut Action Explanation
    Ctrl + Shift + > Increase Font Size Makes text larger.
    Ctrl + Shift + < Decrease Font Size Makes text smaller.
    Ctrl + Shift + F Font Settings Opens font formatting menu.
    Ctrl + 1 Format Cells Opens complete formatting options.
    Alt + H + F + S Font Size Box Directly changes font size.
    Alt + H + F + F Font Selection Changes font type.

    Borders & Cell Appearance

    Shortcut Action Explanation
    Ctrl + Shift + & Apply Border Adds border around selected cells.
    Ctrl + Shift + _ Remove Border Removes cell borders.
    Alt + H + B Border Menu Opens all border options.
    Alt + H + H Fill Color Opens cell background color menu.
    Alt + H + FC Font Color Changes text color.

    Navigation & Selection for Large Sheets

    Shortcut Action Explanation
    Ctrl + Arrow Key Jump to Data Edge Moves quickly through large datasets.
    Ctrl + Shift + Arrow Key Select Data Range Selects all connected data.
    Shift + Mouse Click Select Range Selects a continuous range.
    Ctrl + Click Multiple Selection Selects non-adjacent cells.
    Ctrl + Shift + Space Select Current Table Selects the whole data table.

    Professional Data Cleaning Shortcuts

    Shortcut Action Explanation
    Ctrl + E Flash Fill Automatically detects patterns and fills data.
    Ctrl + Shift + L Add Filter Creates filters on headers.
    Alt + ↓ Open Dropdown Opens filter or list dropdown.
    Ctrl + T Convert to Table Creates a formatted Excel table.
    Ctrl + K Insert Hyperlink Adds a clickable link.
    Ctrl + Shift + V Paste Special Menu Controls exactly how data is pasted.

    Resize all rows equally Select rows → Right click → Row Height

    Excel Pro Tip: Fast Formatting Workflow
    Make a professional report table:
    1. Select entire data (Ctrl + A)
    2. Auto-size everything (Alt + H + O + I)
    3. Turn into table (Ctrl + T)
    4. Make headers bold (Ctrl + B)
    5. Center numbers (Alt + H + A + C)
    6. Wrap long text (Alt + H + W)
    7. Adjust final size manually (Alt + H + O + W)
