# Excel Wizord ✨

**Excel Wizord** is a modern, AI-powered browser application built by **Hackers Lab** that translates plain-English requests into working Excel formulas, step-by-step tutorials, and practical worked examples — or directly modifies uploaded spreadsheets in real time.

## 🔥 Key Features

- **Natural-Language to Formula:** Describe your task in plain English (e.g., *"Look up a price from Sheet2 based on column B and hide errors"*). Get back modern, accurate Excel formulas (`XLOOKUP`, `UNIQUE`, `IFS`, etc.) with simple 1-3 sentence explanations and step-by-step guides.
- **Live Data Modification:** Upload `.xlsx`, `.xls`, or `.csv` files. Preview your data instantly in a live interactive spreadsheet grid powered by **Jspreadsheet CE**, let AI write and execute transformation code directly on your live dataset, and download the modified `.xlsx` workbook immediately.
- **Interactive Excel Pro Cheat Sheet:** Built-in modal library covering pro Excel navigation, formatting, cell sizing, and data cleaning shortcuts.
- **Client-Side & Secure by Design:**
  - **Zero Backend Storage:** Runs entirely in your browser. Your spreadsheets and queries are never stored on any external server.
  - **Local API Key Persistence:** Your Google Gemini API key is securely persisted exclusively within your browser's `localStorage`.
  - **Hardened Security:** Built with strict DOM node generation to eliminate Cross-Site Scripting (XSS) vulnerabilities and configured with HTTP security headers (`X-Frame-Options` & `Content-Security-Policy`) to block iframing and clickjacking attempts.

## 🛠️ Technology Stack

- **Frontend & Build Tool:** Vanilla HTML, CSS, JavaScript, and [Vite](https://vitejs.dev/)
- **Spreadsheet & Excel Processing:** [SheetJS (XLSX)](https://sheetjs.com/) and [Jspreadsheet CE / JSuites](https://jspreadsheet.com/)
- **Artificial Intelligence:** Google Gemini API (`gemini-3.5-flash`) structured content generation & code synthesis
- **UI/UX Aesthetics:** Custom Luminary-styled sleek dark theme with smooth micro-animations and typography from Google Fonts (Playfair Display & Montserrat).

## 🚀 Getting Started (Local Development)

### 1. Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher)
- A valid Google Gemini API Key ([Get one here](https://aistudio.google.com/app/apikey))

### 2. Installation & Run
Clone the repository and start the dev server:

```bash
# Install dependencies
npm install

# Start the Vite development server
npm run dev
```

Open your browser to `http://localhost:5173`, click **Set API Key** in the top navigation bar, and start transforming spreadsheets!

## 📦 Production & Deployment

Excel Wizord is ready for instant zero-config deployments on standard platforms like **Vercel** or **Netlify**.
When deployed to **Vercel**, the included `vercel.json` automatically enforces edge security policies:
- `X-Frame-Options: DENY`
- `Content-Security-Policy: frame-ancestors 'none'`

To generate a static production bundle manually:
```bash
npm run build
# Built static assets will be output to the /dist folder
```
